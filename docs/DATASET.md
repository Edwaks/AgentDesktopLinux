# Паспорт продукта

| Поле | Значение |
|------|----------|
| Название | AgentDesktopLinux |
| Репозиторий | AgentDesktopLinux |
| Категория | агентский слой TaskCapitan для настольных платформ |
| Публичный адрес | https://taskcapitan.ru/ |
| Аудитория | пользователи TaskCapitan и операторы платформенных задач |
| Ценность | связывает поручения TaskCapitan с действиями на поддерживаемой рабочей платформе |
| Основные сущности | поручения, платформы, сеансы, шаги, подтверждения и результаты |
| Ключевые роли | Постановщик, Оператор и Контролёр результата |
| Язык документации | русский |
| Тип описания | публичное пользовательское |

## Ключевые термины

`получение поручений`, `контекст платформы`, `пошаговое выполнение`, `подтверждение действий`, `возврат результата`, `история сеанса`, `контроль состояния`, `Постановщик`, `Оператор`, `Контролёр результата`
